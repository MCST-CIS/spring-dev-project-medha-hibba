Spring Dev Project - Vinyl

Description

Me and my partner created this project to combine our interest in music with interactivity to make it as engaging as possible. We were curious about interactivity, so, with the help of AI, we made the project react to the user's voice. We also added popular album covers in the background to appeal to an audience interested in music, just like us. The purpose of this project was for us to explore each other's interests, find something in common, and create something fun through teamwork.
